本节将指导您开始使用 Goa 进行开发。您将学习如何：

1. [设置开发环境](./1-installation/)，使用 Go 模块和 Goa CLI
2. [创建第一个服务](./2-first-service/)，使用 Goa 的优先设计方法

## 预期结果

使用 Goa 时，您的开发工作流通常遵循以下步骤：

1. **优先设计**：使用 Goa 的 DSL 在 Go 中编写服务定义
2. **生成代码**：使用 Goa CLI 生成样板代码、传输层和文档
3. **实现逻辑**：将业务逻辑添加到生成的服务接口中
4. **测试与运行**：使用生成的客户端和服务器测试您的实现

## 选择您的路径

完成入门指南后，您可以：

- 遵循 [REST API 教程](../3-tutorials/1-rest-api/) 深入了解构建 HTTP 服务
- 探索 [gRPC 服务](../3-tutorials/2-grpc-service/) 创建高效的基于 RPC 的 API
- 学习 [错误处理](../3-tutorials/3-error-handling/) 以设计健壮的服务

## 最佳实践

- **将设计文件保存在单独的 `design` 包中**：这种分离有助于保持 API 设计和实现之间的清晰区别。这使得更容易独立于业务逻辑管理 API 契约的变更。

- **任何设计变更后运行 `goa gen`**：保持生成的代码与设计同步至关重要。运行 `goa gen` 确保您的实现接口、传输层代码和文档始终反映您当前的 API 设计。

- **对生成的代码进行版本控制**：虽然生成的代码可以重新创建，但对其进行版本控制有助于跟踪 API 演进，使部署更可靠，并能够更容易地对 API 变更进行代码审查。它还确保团队成员使用一致的代码，无论他们的本地 Goa 版本如何。

- **使用生成的 OpenAPI/Swagger 文档**：自动生成的 API 文档是开发和验证的有价值资源。它提供了一种交互式探索 API 的方式，可以与利益相关者共享以获取反馈。

- **遵循一致的命名约定**：在设计中对服务、方法和类型使用描述性和一致的名称。这使您的 API 更直观且更易于维护。

- **利用 Goa 的类型系统**：利用 Goa 丰富的类型系统在设计中定义精确的数据结构和验证规则。这减少了样板验证代码并确保一致的数据处理。
