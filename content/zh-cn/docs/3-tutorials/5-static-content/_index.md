提供静态内容是构建 Web 应用的基础。Goa 在 DSL 中提供 `Files` 函数，简化了服务 HTML、CSS、JavaScript、图片等静态资源的过程。本节介绍在 Goa 服务中提供静态内容的多种方法与最佳实践。

## 子章节

1. [提供文件](./1-serving-files.md)  
   学习如何定义端点以服务静态文件与目录。

2. [模板集成](./2-template-integration.md)  
   将 HTML 模板与静态文件服务集成，实现动态内容渲染。

3. [单页应用](./3-single-page-apps.md)  
   配置 Goa 为单页应用（SPA）提供服务并支持客户端路由。
