## Goa 核心教程

通过这些按步骤进行的教程探索 Goa 的核心特性，每个教程都聚焦常见的 API 开发场景。按教程实践，您将获得对 Goa 的设计优先（design‑first）方法、生成代码、传输层、错误处理、流式处理（streaming）等的动手体验。

将这些教程作为循序渐进的指南来掌握 Goa 的设计优先理念。无论您要构建 RESTful 服务还是高级 gRPC 微服务，这些示例都能为真实项目提供坚实基础。
